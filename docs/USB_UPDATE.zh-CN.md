# USB升级M5Stack Cardputer-Adv

打开插件「固件」→扫描USB→选择设备→确认型号/布局→确认升级。数据线必须连接运行Studio服务的那台电脑；如果Studio运行在NAS或云端，浏览器电脑上的USB不会因此出现在列表。

仅支持本项目已有ESP32-S3/8MiB双固件布局；开启安全启动、Flash加密或无法核对安全状态的设备会被拒绝，不修改eFuse。当前随包仍为alpha6应用，版本和SHA显示在页面；插件版本0.3.0-alpha.2不等于重新编译了固件。完整新机首刷、任意bin、任意写入地址、整片擦除及OTA不在此入口范围。

操作依次为：核对USB身份/ROM芯片/8MiB容量，读取完整Flash并在本机持久化私人备份，核对实际分区表，只在0x10000写应用，再读完整Flash核对应用及原厂/配网/存储保留区，最后请求复位。完成状态不等于已启动应用；从原厂菜单进入EkkoStudio后再自行检查。

私有备份含Wi-Fi和登录设置，保存在Studio插件数据目录的usb-backups中，目录0700、文件0600，不能公开上传。默认主机目录是`~/.hermes-web-ui/plugins/global/plugin-data/m5stack-cardputer-adv/usb-backups/<作业ID>/`，修改过Studio状态目录时以宿主paths.dataDir为准。`before.bin`是私人完整Flash，`manifest.json`记录其SHA和目标；两者都不要放进GitHub或聊天。代码包、RPC状态和日志不包含备份内容或凭据。

界面关闭只停止本页观察，不会重复发起或取消已确认的写入；重新打开固件页可查看本账号/Profile作业。开始写入前可取消，开始写入后禁用用户取消；拔线、退出Studio或总超时仍可能留下不完整镜像，没有自动回滚。写入/关闭结果未知或校验失败时不自动重刷，先保留连接和私人备份。结果未知必须明确重新核对并扫描；原生关闭未确认的设备会保持锁定，需停止操作并检查主机和设备。

默认115200设置需要完整读取两次8MiB，实际速度取决于设备与连接，慢UART可能约半小时；本机原生USB实测约2分6秒，不保证其他主机相同。后台总时限90分钟。页面观察10分钟后可暂停，暂停不会终止后台任务，使用「刷新状态」继续查看。不要因进度慢重复点击或拔线。

进入下载模式失败时：侧面开关OFF、拔线、按住G0插线约两秒后松开，黑屏正常；回到页面重新明确扫描和确认。插件不会在打开页面或自动刷新时进入下载模式。

USB依赖采用Node串口和esptool-js，按用户自有StackChan插件的后端架构适配，但没有复制其16MiB/0地址FULL写入或Pulse配对协议。本轮已在本机官方Studio0.8.24完成一次真实同版本重刷，应用/保留区域/私有备份核对和用户启动确认均通过，详见[检查记录](VALIDATION.zh-CN.md)。其他系统、旧版本升级与异常实物场景仍需分别验证。
