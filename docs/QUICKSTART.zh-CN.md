# 三步开始使用

M5 直接连接官方 Studio，插件只是可选的状态、固件校验和指南入口，不是聊天桥接。

1. **准备设备。** 已有兼容固件可继续使用；更新 alpha6 时先看[安装教程](INSTALL.zh-CN.md)，私人备份并核对既有双固件布局，只写 Ekko 应用 `0x10000`，读回核对后开机。未知布局或新机不适用。
2. **首次绑定。** M5 和电脑连接同一 Wi-Fi，电脑打开 Studio，从原厂菜单进入 EkkoStudio。在独立浏览器打开设备显示的 `/device`，选择电脑、登录自己的账号并选 Profile。已有有效绑定可跳过，不把密码交给插件。
3. **开始聊天。** 首页方向键浏览、Tab 选 Studio模型／原生CLI、OK 一次进入。中文拼音＋空格选词，OK 发送；如果仍有拼音预编辑，第一次 OK 只提交，再按一次才发送。Ctrl＋空格切中英文，Fn＋上下翻历史。长 G0 或 Fn＋空格说话、松开发送，采集就绪后最多 5 秒；短 G0／Esc 返回。

新 Agent／Profile 的输入上下文默认中文，首次切英文不保证所有 Agent 都保持英文。仅测试发送时，可在空草稿、空拼音状态输入数字 `1` 再按 OK；有拼音时数字键会选词。

聊天不需要先打开插件，也不需要每次网页登录。电脑 IP 或身份改变时按原生页面重新选择／绑定；本版仅局域网，远程中继不在支持范围。

本地插件候选为 0.3.0-alpha.2，使用官方原生插件中心安装完整本地目录并启用。新增「固件」页的服务端USB应用升级，步骤见[USB升级说明](USB_UPDATE.zh-CN.md)；数据线接运行Studio服务的电脑，只支持已有兼容布局，不提供OTA或自动登录设备。本版验证以[检查记录](VALIDATION.zh-CN.md)为准，旧版记录单独保留。

alpha6 应用可复制固件页的固定公开提交地址到外部浏览器下载；Release 仍是草稿。对应源码已在插件包的 `firmware/source.tar.gz`，暂无独立公开下载链接。当前 Codex 的文字／STT／TTS、过期／普通重启恢复及原生 LAN 登记已有记录，其余实体 Agent 与 Wi-Fi等测试按用户要求暂停；这不影响保留现状日常使用，也不等于完整矩阵通过。
