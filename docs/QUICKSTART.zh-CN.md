# 三步开始使用

M5 直接连接官方 Studio。这个插件只提供管理入口、固件校验和说明，不是聊天桥接，也不是使用前提。以下仅适用于已经装有本项目精确双固件布局的 Cardputer-Adv；未知新机不适用这个应用更新包。

1. **准备设备。** 已有可用兼容固件可直接使用。需要更新时，下载对应发布包，按[详细教程](INSTALL.zh-CN.md)完成私人备份、布局与文件校验，只更新 Ekko 应用并读回核对。保留原厂应用、配网和设置，不整片擦除。
2. **首次绑定。** 电脑打开官方 Studio，M5 与电脑连接同一 Wi-Fi。从原厂菜单进入 EkkoStudio，在独立浏览器打开 M5 显示的 `/device` 地址，选择电脑、登录自己的账号并选 Profile。已有有效绑定可跳过；账号密码只在原生设备页输入。插件偏好只帮助保存入口。
3. **开始聊天。** 左右选择已安装、已授权并配置好的 Agent，按一次 OK 进入；打字后 OK 发送。首页 Tab 可选择并保存「Studio模型／原生CLI」。Ctrl＋空格切换中英文，Fn＋上下翻记录；长按 G0 或按住 Fn＋空格说话、松开发送，单次最长 5 秒，不需要 SD 卡。短 G0 或 Esc 返回，首页再返回原厂菜单。

alpha.5 清单已显式声明上述运行模式和 G0 操作；具体 Agent 支持哪些模式依照官方路由，未支持的模式会明确提示。本文描述候选固件的设计操作，本版实机验收尚待完成。

聊天可以直接进行，日常无需先打开插件或反复网页登录。电脑身份变化、认证失效等情况仍按设备提示重新绑定。当前发布范围为局域网；电脑中继在线不代表 M5 已支持跨网。

要使用可选插件时，在 Studio「插件中心」→「安装插件」粘贴已公开仓库地址 `https://github.com/thursdaycapital/ekko-studio-plugin-cardputer-adv`，确认信任并安装，再点「启用」。官方 0.8.24 的普通 Chrome 流程已实测，会自动固定到安装时的完整提交，用户不用手输 40 位 SHA。四个页面、真实设备列表与捆绑文件校验均通过；这些插件检查不等于本版 M5 已在线或完成实机验收。插件不提供一键 USB 刷写，不接收密码或 API Key。
