## 设备交互与原生连接

左右浏览固定 16 Agent，OK 激活后进入聊天；首页 Tab 选择并保存「Studio模型／原生CLI」，不自动换 Agent。Studio 模型依据官方兼容配置选择；原生 CLI 使用该运行时的默认设置，目录探测不等于真实授权成功。Esc 或短 G0 返回，长 G0 或 Fn＋空格按住说话、松开发送；Fn＋上下翻记录，Ctrl＋空格切换中英文。保留 12px 中文、真实头像、启动画面、按键声和独立原厂工具。

语音最多五秒，在 RAM 压缩暂存，逐块转 PCM WAV 上传官方 STT；TTS 流式播放。聊天语音不依赖 SD，不初始化、清扫或格式化 SD 与内置存储分区。原厂独立 SD 录音工具仍归原厂应用。

设备使用官方 `/chat-run`、原生鉴权与 `/global-agent` 状态通道；不依赖本插件转发聊天，不要求修改电脑后端。本版范围为局域网，不提供跨网远程、Studio OTA、自动监听或任意新插件 Agent 路由。发送中断后保留草稿，Fn＋R 核对最新记录及后台状态；只有完成核对后，Ctrl＋OK 才可确认已查看，固件不自动重发。

## 已知问题与限制

| 严重性 / 置信度 | 边界 |
| --- | --- |
| 高 / 高 | 没有新机首刷包；未知布局不能直接安装应用。 |
| 中 / 高 | alpha.5 尚未完成 M5 运行验收及完整恢复矩阵，不称全面兼容正式版。 |
| 中 / 高 | Studio 模型模式只接受 chat_completions、codex_responses、anthropic_messages；缺模型、CLI 或授权时需修复电脑配置，固件不能代替授权。 |
| 中 / 高 | 官方模型接口可能返回 API Key；插件不调用模型接口，不能宣称固件从不接触密钥。 |
| 中 / 高 | 原生设备 HTTP 管理以可信局域网为边界，不应映射公网。 |
| 中 / 高 | 部分头像及启动视频的独立再分发授权尚未完整确立，保留来源与限制。 |
| 中 / 高 | 官方 iframe 没有 WebSerial、直接网络或下载能力；插件仅给可复制地址和刷写指引。 |
| 低 / 高 | STT/TTS 必须配置服务器端提供方，仅浏览器语音识别不能供设备使用。 |
| 低 / 高 | 设备表无板型 / IP，插件不能据名称自动识别真实 Cardputer-Adv。 |
| 低 / 高 | 完整五秒内存、采集溢出、栈余量、长回复与故障恢复仍须按当前镜像记录。 |
| 低 / 高 | 不承诺字节级可重建或完整最终镜像 SBOM；旧回退版可能依赖电脑补丁。 |

解压 `firmware/source.tar.gz` 后按 `firmware/RELINK.md` 构建和修改。原厂独立应用、私人完整备份、NVS、认证数据和原始日志不在公开包中。
