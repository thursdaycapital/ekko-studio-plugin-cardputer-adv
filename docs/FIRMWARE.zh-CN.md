## 交互与协议

方向键浏览16 Agent，首页Tab选Studio模型／原生CLI，OK激活后进入。Studio模式按官方兼容配置选择实际模型并提示，不自动换Agent；原生模式使用电脑该CLI配置。目录的auth_required/error提示在明确Native默认模型路径中可允许尝试，但不保证真实运行成功；HTTP鉴权拒绝、未安装、超时和坏响应仍拒绝。

短G0／Esc返回，长G0或Fn＋空格按住说话、松开发送，Fn＋上下翻记录，Ctrl＋空格切中英文。IME按Agent／Profile／绑定上下文独立保存，新上下文默认中文；有拼音预编辑时OK先提交，再按才发送。

语音采集就绪后最多5秒，16kHz单声道在RAM以IMA4有界暂存，流式还原WAV上传官方STT，TTS流式播放。不使用SD、不初始化或清扫SD／内置存储；原厂独立SD录音工具继续由原厂应用提供。

使用官方原生登录、`/chat-run`和`/global-agent`状态通道，不依赖插件转发、电脑补丁或新桥接。本版只支持局域网，没有远程、OTA、自动监听或任意插件Agent路由。未确认发送先Fn＋R核对，再按提示Ctrl＋OK确认已查看，不自动重发。

## 已知问题与限制

| 严重性／置信度 | 事实与范围 |
|---|---|
| 高／高 | 不提供新机首刷镜像；未知布局不得直接写应用。 |
| 高／高 | Grok官方CLI拒绝`response.metadata`流事件，官方网页同样复现；固件只能正确提示，未改提供方或换Agent。 |
| 高／高 | Qoder Native实际模型不可用且目录提示auth_required，未替用户更改模型或授权。 |
| 中／高 | Claude独立API补充轮60秒超时，普通Chrome另一会话成功；两份记录分别保留，不互相覆盖。 |
| 中／高 | 仅21,264B应用槽余量、无PSRAM；当前有限录音数据不代表最坏长回复／故障负载已验证。 |
| 中／高 | alpha5的PEM换行重登故障已由alpha6最小修复，真实过期与普通重启恢复已通过；不据此宣布Wi-Fi／全部恢复通过。 |
| 中／高 | 电脑IP改变不会自动迁移保存的LAN入口，需原生设备页重新选择／登录；同入口掉线恢复不等跨网迁移。 |
| 中／高 | namespace ready不等于目录已登记；本M5登记和LAN状态有独立证据，不根据设备名猜板型或IP。 |
| 中／高 | 官方模型接口可能返回API Key；插件不读取该配置，不能宣称固件从不接触密钥。 |
| 中／高 | 管理网页以可信局域网为边界，不应映射公网。部分头像／启动素材的独立再分发授权仍须按原声明核对。 |
| 范围边界／高 | 无远程中继、OTA或插件内USB刷写。SDK iframe无直接联网／下载权限，应用地址需复制到外部浏览器；包内源码从分发包提取。 |
| 低／高 | STT／TTS需要服务器端可用配置；仅浏览器语音识别不能供设备使用。 |
| 低／高 | 不承诺字节级重建或完整最终镜像SBOM，旧回退版可能需要其匹配电脑扩展。 |
