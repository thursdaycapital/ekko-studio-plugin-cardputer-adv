为适应官方 Studio 单图标 256,000 B 上限，使用标准 WebP 工具缩放至 512×512、保留透明背景并无损编码。图标 130,292 B，SHA-256 为 `c017d40ffecbf80bdb08603a9b03585925a5978bc8d049de9bb600e4b9881771`。没有重新绘制或更改产品外观。
